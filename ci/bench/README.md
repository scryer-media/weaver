# Benchmarks

The Usenet client benchmark harness (`nntpbench`, `nntpshaper`, the client
adapters, fixture generator and published results) lives in its own
repository: <https://github.com/scryer-media/usenet-bench>. It measures released
Weaver images and has no dependency on this tree.

The scripts in this directory are the standalone CPU-tier profiling runs
(AVX2 / AVX-512 on AWS) used during kernel work.
